### Hi, I'm Nitin 👋

A builder at heart. I like taking ideas from zero to one, through the ambiguity, until they're working products. Backend systems, developer tools, and lately a lot of AI agents.

#### Principles I operate by

- **Simplicity first.** Add complexity only when the problem demands it.
- **Understand before solving.** Then build the simplest thing that works.
- **Build over overthinking.** Ship a prototype, learn from reality, iterate.
- **Own it end to end.** From spotting the problem to shipping and maintaining the fix.
- **Pragmatism over dogma.** Technology is a tool, not an identity.
- **Impact over activity.** Busy is not the same as progress.
- **Automate what can be automated.**
